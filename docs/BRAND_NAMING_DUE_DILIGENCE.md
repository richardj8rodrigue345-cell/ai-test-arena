# Brand Naming Due Diligence Gate

This document exists to prevent premature public naming decisions.

AITestArena is currently a working/prototype name. Before any major public launch, X/Twitter campaign, product hunt style announcement, outreach campaign, or long-term domain commitment, the name must pass this due diligence gate.

## Hard rule

Do not treat a name as final until it has a written naming check.

A name can be used as a temporary prototype label, but public brand commitment requires a green status from this document's checklist.

## Why this gate exists

The current space has close neighbors around AI forecasting, prediction markets, benchmarks, and arena-style naming. Generic names with `AI`, `test`, `prediction`, `forecast`, `bench`, and `arena` can collide semantically even if they are not exact legal conflicts.

The goal is not only legal safety. The goal is distinct product positioning.

## Naming risk levels

### Red

Do not use as final brand if:

- exact name already used by a relevant AI / benchmark / forecasting / agent product
- name is very close to an active neighboring project
- name sounds like a generic category rather than a product
- domain is unavailable or owned by a confusing neighbor
- GitHub/X handles are unavailable in a way that creates confusion
- name leans toward gambling, betting, trading, or financial-return framing

### Yellow

Use only as prototype if:

- exact match appears unused, but similar concepts exist nearby
- name is descriptive but weakly distinctive
- domain is available but social handles are unclear
- name may require explanation to avoid prediction-market/gambling confusion

### Green

Candidate for public brand if:

- exact phrase has no obvious relevant conflicts in public search
- domain path is available or practically obtainable
- GitHub repo name is available or can be made cleanly
- X/social handle is available or acceptable variant exists
- name clearly fits the product thesis
- name does not overclaim performance or imply real-money trading
- name is distinct from existing `Arena` / prediction-market benchmarks

## Current naming direction

Avoid names that center on:

- `Arena` as the main differentiator
- `TestArena`
- `Prediction Arena`
- `Foresight Arena`
- real-money / trading / betting language

Prefer names around:

- public track record
- calibration
- forecast trace/history
- agent proof over time
- transparent scoring
- virtual risk discipline

## Launch hold

Before the first serious public X/Twitter launch, run this gate and record the result.

If no clearly better green name is found quickly, AITestArena may continue as a working prototype name, but public copy should avoid over-investing in it as a final long-term brand.

## Safe public phrasing while name is unresolved

Use:

> AITestArena is a working-name prototype for a public paper benchmark where AI agents make forecasts, manage virtual credits, and build a transparent track record.

Avoid:

> AITestArena is the final brand.
