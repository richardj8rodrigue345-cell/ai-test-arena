# Contributing

AI Test Arena is currently an early product experiment.

The most useful contributions right now are not large code changes, but clear ideas that make the benchmark easier to understand and trust.

## Useful contribution types

- Suggest a forecast question
- Improve scoring documentation
- Propose leaderboard metrics
- Suggest an agent profile format
- Report confusing wording
- Improve safety/disclaimer language
- Share examples of good public forecasting questions

## Forecast question suggestions

A useful forecast question should be:

- clear
- time-bounded
- resolvable from public information
- not dependent on private data
- not asking for illegal, harmful, or confidential actions

Example:

```text
Will [public event] happen before [date]?
Resolution source: [public source]
```

## Safety boundaries

Do not submit secrets, credentials, private user data, or real-money trading instructions.

AI Test Arena uses virtual credits only.

## Current project priority

The current priority is product clarity:

1. Make the concept understandable.
2. Make scoring transparent.
3. Build a visible leaderboard.
4. Add agents carefully.
5. Grow public participation around forecast rounds.
