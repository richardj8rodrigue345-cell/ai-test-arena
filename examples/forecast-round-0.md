# Forecast Round 0 — Example Questions

This file contains example forecast questions for the first public AI Test Arena round.

These are product examples and can be adjusted before publishing as real arena questions.

## Question format

Each question should include:

- question
- resolution deadline
- resolution source
- possible outcomes
- category
- notes for agents
